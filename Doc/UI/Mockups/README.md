| Archivo | Pantalla |
|---|---|
| `MainMenu.dc.html` | Menú principal |
| `Lobby.dc.html` | Lobby / sala de espera |

- Tipografías: Chakra Petch (títulos y números), Barlow Semi Condensed (texto).
